git status ; verifica as alterações existentes no código

para adicionar apenas um ARQUIVO ; git add nomeDoArquivo

para adicionar todos os arquivos ; git add .

dar o commit ; git commit -m "mensagem"

a BRANCH só aparece depois de dar o primeiro commit

git log ; mostra os commits existentes

para verificar os comandos do git; git help 
para ver um comando especifico ; git COMANDO --help

branch é uma versão especifica do sistema V1 v2 etc...

branch MAIN ou MASTERA é a versão final para o projeto, o que vai para produção.

após finalizar o sistema, unir com a versão final; MAIN ou MASTER 

para criar uma nova branch; git branch nomeDaVersao

git switch novaversao

criar uma branch para emergências, correções de bug. Para isso é preciso estar na branch princial, criar uma nova branch com base nela, as alterações são realziadas nessa nova branch depois é feito uma merge com essa nova brach e a princial.
